### One recommendation before you start development

Since this is an **Android-only app**, I recommend **Flutter + Isar + Riverpod** instead of React Native or Kotlin for this project.

Why?

- Excellent Material 3 support.
- Very fast UI performance.
- Offline-first architecture is straightforward.
- Great local database with Isar.
- Easier future expansion to iOS if you ever decide to publish there.
- Large ecosystem for charts, notifications, and calendars.

The next file should be **`DESIGN_SYSTEM.md`**, where we'll define the entire visual language (colors, typography, spacing, components, animations, icons, navigation, dark mode, and Material 3 guidelines) so the app feels polished and consistent instead of like a collection of screens.
